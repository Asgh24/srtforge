# SRTForge

ترجم ملفات الترجمة SRT مع أي واجهة برمجة لوحات اللغة — **مجزّأة، متوازية، وقابلة للاستئناف**.

SRTForge هو تطبيق سطح مكتب ويندوز (PySide6) يقسّم ملف الترجمة إلى أجزاء صغيرة،
ويرسلها إلى نقطة نهاية متوافقة مع OpenAI (OpenRouter، OpenAI، Together، Ollama محلي، …)
**بشكل متزامن**، ويكتب ملف `.srt` منسّق بشكل صحيح. يتكيّف حجم الأجزاء مع نافذة السياق
للوحة اللغة، لذا حتى اللوحات ذات السياق الصغير (8k) تعمل بشكل جيد.

## المميزات

- 🌗 **الوضع الداكن افتراضيًا**، الوضع الفاتح، أو متابعة النظام.
- 🧩 **تجزئة ذكية** — يتم تجميع الترجعات دون كسر جملة أبدًا، بحجم مناسب
  لنافذة السياق الحقيقية للوحة.
- 📊 **شريط تقدم جميل** — شبكة كل جزء، النسبة المئوية، الوقت المتبقي.
- 🔁 **استئناف / إعادة محاولة / إلغاء** — ملف جانبي (`<name>.srtforge.json`)
  يحتفظ بسجل الأجزاء المنجزة؛ في حالة التعطل، يُعاد ترجمة المتبقي فقط.
- ⚡ **طلبات متوازية** — قابلية ضبط التزامن (افتراضي 6).
- 🎛️ **اكتشاف تلقائي لحجم سياق اللوحة** من `/models`، أو إدخال يدوي لأي لوحة مخصصة.
- 🌐 **كشف تلقائي للغة المصدر** (`auto`) أو تعيين صريح؛ أي لغة هدف.
- ✍️ **أوامر مخصصة** — تعليمات الترجمة قابلة للتعديل بالكامل
  (النبرة، المصطلحات، المفردات التقنية، إلخ).
- 👤 **ملفات تعريف API** — حفظ عدة روابط URL ومفاتيح (OpenRouter، 9Router، وغيرها).
- 📚 **قائمة انتظار دفعية** — أضف عدة ملفات `.srt` وترجمها دفعة واحدة.
- 👀 **معاينة** — الترجعات الأصلية والمترجمة جنبًا إلى جنب، قابلة للبحث.
- 🪵 **سجل فوري** — ملون، قابل للحفظ.
- 🧵 **مناسب للسياق الصغير** — يعمل مع لوحات سياق 8k فورًا.

## التثبيت

### الطريقة السهلة (لا حاجة لبايثون)

1. قم بتنزيل `SRTForge.exe` من صفحة [الإصدارات](https://github.com/YOURUSER/srtforge/releases).
2. قم بتشغيله. انتهى.

### من المصدر

يتطلب بايثون 3.11+.

```bash
git clone https://github.com/YOURUSER/srtforge.git
cd srtforge
python -m venv .venv
.venv\Scripts\activate        # ويندوز
pip install -e .
srtforge                      # أو: python -m srtforge
```

اختياري — تقدير أفضل للتوكنات للوحات عائلة OpenAI:

```bash
pip install -e .[tokenize]
```

## بداية سريعة

1. افتح **API Profiles** (شريط الأدوات) → **New**، وأدخل عنوان نقطة النهاية ومفتاح API الخاص بك.
   SRTForge يعمل مع أي واجهة برمجة متوافقة مع OpenAI. أمثلة:
   - **OpenRouter:** `https://openrouter.ai/api/v1` — المفتاح: `sk-or-…`
   - **9Router:** `https://9router.com/api/v1` — أو أي نقطة نهاية توجيه مخصصة
   - **OpenAI:** `https://api.openai.com/v1`
   - **محلي (Ollama, LM Studio):** `http://localhost:11434/v1`
2. اختر **Model** — SRTForge يسحب قائمة اللوحات (مع أحجام السياق) من `/models` تلقائيًا.
   زر `Refresh` يعيد السحب.
3. اضغط **Add SRT…** واختر ملف(ات) الترجمة الخاصة بك.
4. اختر لغة **Source** (`auto` أو محددة) و **Target**.
5. اضغط **Start** (أو `Ctrl+Enter`).

يتم كتابة المخرج بجانب المصدر باسم `<name>.out.srt`. إذا فشلت بعض الأجزاء،
يُعاد إرسالها فقط عند التشغيل التالي (استئناف).

## كيف تعمل التجزئة

كل وحدة ترجمة (cue) هي وحدة غير قابلة للتقسيم — لا نقسم أي ترجمة إلى نصفين أبدًا.
نقدر التوكنات (باستخدام tiktoken للوحات OpenAI، وطريقة استرشادية تأخذ CJK بعين الاعتبار
في الحالات الأخرى)، ثم نملأ الأجزاء بطريقة الجشع حتى:

```
الميزانية = طول_السياق × هامش_الأمان − توكنات_المخرج − تكلفة_الأوامر
```

`هامش_الأمان` (افتراضي 0.85) و `الحد_الأقصى_لتوكنات_المخرج` قابلان للتعديل في
**Settings**. طول سياق اللوحة يُقرأ من `/models`
(`context_length` / `top_provider.max_completion_tokens`)؛
إذا تعذر اكتشاف اللوحة، يمكنك كتابة أي معرف في مربع اللوحة وتحديد سياق يدوي في Settings.

الأوامر تطلب مخرج JSON دقيق (`{"translations": [{"i":…,"t":…}]}`)
ويقوم العميل بالتحقق منه وإصلاحه — لا مفاجآت "أضافت اللوحة تعليقًا".

## الخصوصية

- الإعدادات (بما في ذلك مفاتيح API) تُخزَّن **محليًا** في
  `%APPDATA%/srtforge/settings.json`. المفاتيح لا تُسجل أبدًا.
- لا تتبع، لا اتصالات شبكة باستثناء نقطة النهاية التي اخترتها
  (`/models` و `/chat/completions`).
- محتوى الترجمة يُرسل إلى مزود API الذي قمت بتكوينه — هذا هو جوهر التطبيق.
  إذا كنت بحاجة إلى خصوصية كاملة، وجّهه إلى لوحة محلية
  (Ollama، LM Studio) عبر `http://localhost:11434/v1`.

## التطوير

```bash
pip install -e .[dev]
pytest                 # اختبارات الوحدة (بدون شبكة)
ruff check src tests
```

### بناء ملف .exe

```bash
pip install pyinstaller
pyinstaller srtforge.spec
# → dist/SRTForge.exe
```
