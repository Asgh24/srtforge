# SRTForge

فایل‌های زیرنویس SRT را با هر API مدل زبانی ترجمه کنید — **تکه‌تکه، موازی و قابل ادامه**.

SRTForge یک برنامه دسکتاپ ویندوز (PySide6) است که فایل زیرنویس را به تکه‌های کوچک تقسیم می‌کند،
آن‌ها را به یک endpoint سازگار با OpenAI (OpenRouter، OpenAI، Together، Ollama محلی، …)
به صورت **هم‌زمان** ارسال می‌کند و خروجی را به صورت `.srt` استاندارد برمی‌گرداند. اندازه تکه‌ها
بر اساس پنجره زمینه (context) مدل تنظیم می‌شود، بنابراین حتی مدل‌های با زمینه کوچک (8k) هم
بدون مشکل کار می‌کنند.

## ویژگی‌ها

- 🌗 **تم تیره به صورت پیش‌فرض**، تم روشن، یا هماهنگ با سیستم.
- 🧩 **تکه‌بندی هوشمند** — زیرنویس‌ها بدون شکستن جمله گروه‌بندی می‌شوند و اندازه آن‌ها
  بر اساس پنجره زمینه واقعی مدل تنظیم می‌شود.
- 📊 **نوار پیشرفت زیبا** — شبکه نمایش هر تکه، درصد انجام، زمان باقی‌مانده.
- 🔁 **ادامه / تلاش مجدد / لغو** — فایل جانبی (`<name>.srtforge.json`) تکه‌های انجام‌شده را
  به خاطر می‌سپارد؛ در صورت قطع شدن، فقط باقی‌مانده دوباره ترجمه می‌شود.
- ⚡ **درخواست‌های موازی** — هم‌زمانی قابل تنظیم (پیش‌فرض ۶).
- 🎛️ **تشخیص خودکار اندازه زمینه مدل** از `/models`، یا وارد کردن دستی برای هر مدل سفارشی.
- 🌐 **تشخیص خودکار زبان مبدأ** (`auto`) یا تعیین صریح؛ هر زبان مقصدی.
- ✍️ **پرامپت سفارشی** — دستورالعمل‌های ترجمه کاملاً قابل ویرایش‌اند
  (لحن، واژه‌نامه، اصطلاحات فنی و …).
- 👤 **پروفایل‌های API** — ذخیره چندین URL و کلید (OpenRouter، 9Router، و دیگران).
- 📚 **صف دسته‌ای** — چند فایل `.srt` اضافه کنید و همگی یکجا ترجمه شوند.
- 👀 **پیش‌نمایش** — زیرنویس اصلی و ترجمه‌شده کنار هم، قابل جستجو.
- 🪵 **لاگ لحظه‌ای** — رنگی، قابل ذخیره.
- 🧵 **سازگار با زمینه کوچک** — از همان ابتدا با مدل‌های 8k کار می‌کند.

## نصب

### راه آسان (بدون نیاز به پایتون)

1. فایل `SRTForge.exe` را از صفحه [Releases](https://github.com/YOURUSER/srtforge/releases) دانلود کنید.
2. اجرا کنید. تمام.

### از سورس

نیازمند پایتون 3.11+.

```bash
git clone https://github.com/YOURUSER/srtforge.git
cd srtforge
python -m venv .venv
.venv\Scripts\activate        # ویندوز
pip install -e .
srtforge                      # یا: python -m srtforge
```

اختیاری — تخمین بهتر توکن‌ها برای مدل‌های خانواده OpenAI:

```bash
pip install -e .[tokenize]
```

## شروع سریع

1. **API Profiles** (نوار ابزار) → **New** را باز کنید و آدرس endpoint و کلید خود را وارد کنید.
   SRTForge با هر API سازگار با OpenAI کار می‌کند. مثال‌ها:
   - **OpenRouter:** `https://openrouter.ai/api/v1` — کلید: `sk-or-…`
   - **9Router:** `https://9router.com/api/v1` — یا هر endpoint روتینگ سفارشی
   - **OpenAI:** `https://api.openai.com/v1`
   - **محلی (Ollama, LM Studio):** `http://localhost:11434/v1`
2. یک **Model** انتخاب کنید — SRTForge لیست مدل‌ها (با اندازه زمینه) را به طور خودکار از
   `/models` دریافت می‌کند. دکمه `Refresh` دوباره دریافت می‌کند.
3. **Add SRT…** را بزنید و فایل(های) زیرنویس خود را انتخاب کنید.
4. زبان **Source** (`auto` یا مشخص) و **Target** را انتخاب کنید.
5. **Start** را بزنید (یا `Ctrl+Enter`).

خروجی کنار فایل اصلی به صورت `<name>.out.srt` ذخیره می‌شود. اگر برخی تکه‌ها ناموفق باشند،
فقط همان‌ها در اجرای بعدی دوباره ارسال می‌شوند (ادامه).

## تکه‌بندی چگونه کار می‌کند

هر زیرنویس (cue) یک واحد تقسیم‌ناپذیر است — ما هرگز یک زیرنویس را نصف نمی‌کنیم.
توکن‌ها را تخمین می‌زنیم (tiktoken برای مدل‌های OpenAI، یک روش اکتشافی آگاه از CJK
در غیر این صورت) و سپس به صورت حریصانه تکه‌ها را پر می‌کنیم:

```
بودجه = context_length × safety_margin − output_tokens − prompt_overhead
```

`safety_margin` (پیش‌فرض 0.85) و `max_output_tokens` در **Settings** قابل تنظیم‌اند.
اندازه زمینه مدل از `/models` خوانده می‌شود (`context_length` / `top_provider.max_completion_tokens`)؛
اگر مدلی قابل تشخیص نبود می‌توانید هر شناسه‌ای را در کادر مدل تایپ کنید و یک زمینه دستی
در Settings تنظیم کنید.

پرامپت خروجی JSON دقیق درخواست می‌کند (`{"translations": [{"i":…,"t":…}]}`)
و کلاینت آن را بررسی و تعمیر می‌کند — بدون سورپرایز «مدل نظر اضافه کرد».

## حریم خصوصی

- تنظیمات (شامل کلیدهای API) **به صورت محلی** در `%APPDATA%/srtforge/settings.json`
  ذخیره می‌شوند. کلیدها هرگز ثبت (log) نمی‌شوند.
- بدون تله‌متری، هیچ تماس شبکه‌ای به جز endpoint انتخابی شما
  (`/models` و `/chat/completions`).
- محتوای زیرنویس به ارائه‌دهنده API که پیکربندی کرده‌اید ارسال می‌شود — این اصل کار
  برنامه است. اگر حریم خصوصی کامل می‌خواهید، آن را به یک مدل محلی
  (Ollama، LM Studio) از طریق `http://localhost:11434/v1` هدایت کنید.

## توسعه

```bash
pip install -e .[dev]
pytest                 # تست‌های واحد (بدون شبکه)

```

```bash
pip install pyinstaller
pyinstaller srtforge.spec
# → dist/SRTForge.exe
```
